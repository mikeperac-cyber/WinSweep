# WinSweep Privacy Policy

**Effective date: November 20, 2026**

WinSweep is a Windows desktop utility published by Mike Perac. This policy explains what information the current version of WinSweep accesses and stores.

## Information WinSweep accesses

WinSweep reads local Windows system information to show device status, including processor and memory use, storage, battery, network adapter status, and running processes. Depending on the feature you use, it may also inspect file and folder names, sizes, dates, installed application details, and selected Windows settings or caches so it can show cleanup candidates and perform actions you approve.

WinSweep does not intentionally collect or transmit this information to the publisher. The current app contains no account registration, analytics, advertising, or online payment feature.

## Information stored on your device

WinSweep stores settings and an action history under your Windows local application data folder. If you use its quarantine feature, recovery data is also stored locally so you can restore items. These files remain on your device unless you choose to share them. WinSweep relies on Windows account and file permissions to restrict access to this data; it does not transmit it to the publisher or disclose it to third parties. You can remove them by uninstalling the app and deleting any remaining WinSweep data folders; deleting quarantine data removes the ability to restore items kept there.

## Your choices and control

WinSweep displays scan results for review before carrying out cleanup actions. You control whether to run scans and approve actions. Windows may ask for permission when an operation requires administrator access. Items moved to the Recycle Bin or WinSweep quarantine can generally be restored using the corresponding Windows or WinSweep recovery feature, subject to the app's displayed status.

## Children

WinSweep is a general-purpose Windows utility and is not designed to collect personal information from children.

## Changes to this policy

This policy may be updated when WinSweep's features or data practices change. The effective date above will be revised when that happens.

## Contact

For privacy questions about WinSweep, contact the publisher through the [WinSweep GitHub repository](https://github.com/mikeperac-cyber/WinSweep).
